# Iris-Flower-Classification
This is a basic Machine Learning project where I built a model to classify iris flowers into different species using their features like sepal and petal length/width.

## Dataset

Used the famous Iris dataset:
https://archive.ics.uci.edu/ml/machine-learning-databases/iris/iris.data

## What I did
Loaded and explored the dataset
Trained ML models
Tested and evaluated performance

##  Models Used
Logistic Regression
KNN

## Learning

This project helped me understand the basics of classification and the ML workflow.

## Tech Stack

Python, Pandas, NumPy, Scikit-learn
